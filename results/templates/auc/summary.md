# Az élő sablon-pontszám szétválasztó ereje (AUC, kereskedés nélkül)

Sablonok a másik évből. A = orderflow, B = ár (hatékonyság), C = (A + B) / 2. AUC súlyozva (a nem ZigZag-minta súlya 10); 0,5 = véletlen. jó = forduló + lezárult nem forduló, rossz = érvénytelenült.
